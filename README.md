#  Interface - Gestion des Étudiants (Frontend)

Ce dépôt contient l'interface utilisateur du projet. 
Elle est développée en HTML, Bootstrap et JavaScript.

##  Prérequis

- XAMPP (Apache)
- Un navigateur web moderne
- L'API backend doit être en cours d'exécution

##  Installation

1. Cloner le dépôt
2. Placer le dossier dans C:\xampp\htdocs\
3. Vérifier l'URL de l'API dans script.js
4. Démarrer Apache dans XAMPP
5. Ouvrir index.html dans le navigateur

##  Fonctionnalités

- Afficher la liste des étudiants
- Ajouter un étudiant
- Ajouter une note
- Modifier un étudiant
- Supprimer un étudiant
- Rechercher un étudiant par nom/prénom

##  Technologies utilisées

- HTML5 (Structure)
- Bootstrap 5 (Design)
- JavaScript (Interactions)
- Fetch API (Communication avec le backend)
